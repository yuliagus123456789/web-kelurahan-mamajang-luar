# Website Kelurahan Mamajang Luar - Design & Code Rules

## Core Design Principles (Anti-Slop Adherence)
1. **Identitas Lokal Makassar**:
   - Palette warna resmi: `makassar` (Maroon/Crimson #8B2342) dan `gold` (#C8940E, #E5A811), berakar pada nuansa budaya Kota Makassar.
   - Tipografi: `Plus Jakarta Sans` (font modern rancangan desainer Indonesia).
   - Jangan pernah mengganti warna lokal ini dengan generic blue-purple gradient AI slop.

2. **No Technique Without Purpose (Anti-Slop R-01)**:
   - Dilarang menambahkan floating blur orbs, glowing particles, atau background grid tanpa fungsi/makna.
   - Shimmer dan shadow hanya digunakan secara terbatas pada elemen prioritas tinggi (misalnya CTA utama).
   - Card highlights dan list berita harus memiliki hierarki visual (featured card vs supporting cards), bukan kotak identik copy-paste.

3. **Domain-Specific Iconography (Anti-Slop R-17)**:
   - Dilarang menggunakan icon `Sparkles` sebagai dekorasi generik AI.
   - Gunakan icon semantik sesuai domain kelurahan: `Landmark`, `ShieldCheck`, `Activity`, `SlidersHorizontal`, `Calculator`, `Award`, `Store`, `Users`.

4. **Data Riil & Kredibel (Anti-Slop R-05 & C-3)**:
   - Semua statistik kependudukan (3.025 jiwa, 3 RW / 16 RT, 878 KK, 36+ UMKM) dan nomor satgas adalah data resmi wilayah Mamajang Luar. Dilarang mengganti dengan data placeholder tiruan tanpa instruksi pengguna.
